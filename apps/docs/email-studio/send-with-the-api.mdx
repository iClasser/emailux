---

<Steps>
  <Step title="Create an API key">
    In your EmailUX dashboard, create an API key and store it as `EMAILUX_API_KEY`.
  </Step>
  <Step title="Install the client">
    ```sh
    npm install @emailux/api-client
    ```
  </Step>
  <Step title="Render to HTML">
    ```ts
    import { EmailUxApiClient } from '@emailux/api-client';

    const client = new EmailUxApiClient({
      apiKey: process.env.EMAILUX_API_KEY!,
      sendgridDomain: 'mail.yourdomain.com',
    });

    const result = await client.render({
      experienceId: 'welcome-email',
      locale: 'en-US',
      data: { firstName: 'Ada' },
    });
    ```

    Enable the template for that SendGrid domain with **Set SendGrid domain** or **Manage templates**; a template with no live version is not available until one is marked live.
  </Step>
  <Step title="Or deliver it">
    `deliver()` renders and queues the send through your connected provider. See the [API client reference](/api/api-client) for provider options and response codes.
  </Step>
</Steps>
