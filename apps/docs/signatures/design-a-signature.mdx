You design a signature once. Merge fields fill in each person's own details when it is published.

<Steps>
  <Step title="Create the signature">
    Open **Signatures** and choose to add a new signature. Give it a name your team will recognize, such as *Sales signature*.
  </Step>
  <Step title="Pick a layout">
    Start from one of twelve layouts, then adjust.

    - Header and body
    - Three rows or four rows
    - Two, three or four columns
    - Two by two grid
    - Left cell beside two stacked cells
    - Two columns over a footer
    - Two stacked cells beside a right cell
    - Header over two columns
    - Header, two columns and footer
  </Step>
  <Step title="Insert blocks">
    Use the insert dialogs to add a personal block, contact details, an address, social links or a table. Confirm with **Insert block** or **Insert layout**.
  </Step>
  <Step title="Add merge fields">
    Drop in fields where a person's details belong, so nothing is hard-coded. Every field has a fallback, so a missing mobile number never leaves a dangling label.
  </Step>
  <Step title="Add your logo and links">
    Pick the logo and banners from your organization's assets and set the links.
  </Step>
  <Step title="Save and preview">
    Save the signature and check the preview and code preview. Assign it with a [rule](/signatures/assignment-rules) before publishing.
  </Step>
</Steps>

## Built-in person fields

| Field | Field |
| --- | --- |
| Full name | Phone |
| First name | Mobile |
| Last name | Street |
| Email | City |
| Job title | State / region |
| Department | Postal code |
| Employee ID | Country |
| Manager | Location |

Two more are available: **Profile photo** and **Organization name**.

## Custom fields

Open **Settings** and add a custom field for anything your directory does not carry, such as pronouns, certifications or a booking URL. Custom fields can be text or links, and they appear in the editor next to the built-in ones.

## Make it look right everywhere

EmailUX generates table-based HTML with inline styles, the approach mail clients handle most consistently. Keep the design simple, use hosted images with a width set, and send yourself a test message in the clients your recipients use.
