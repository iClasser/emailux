The [`@emailux/api-client`](https://www.npmjs.com/package/@emailux/api-client) package calls the EmailUX HTTP API with two operations:

- **`render()`** returns the HTML and subject for an Email Studio template.
- **`deliver()`** renders the template and sends it through the provider you connected: SendGrid, Gmail (Google Workspace) or SMTP.

The same snippets appear in your dashboard under **Emails, Providers and API Keys, How to use API**.

<Note>
  EmailUX is not the sender of record. Your provider delivers the email, so your domain and reputation stay yours.
</Note>

## Before you start

<Steps>
  <Step title="Connect a provider">
    Add a SendGrid domain, a Gmail (Google Workspace) account or an SMTP mailbox. See [Providers](/providers/overview).
  </Step>
  <Step title="Create an API key">
    Generate a key for your domain or provider. See [API keys](/providers/api-keys).
  </Step>
  <Step title="Design a template">
    Build the email in Email Studio and note its **experience ID** (the email ID). See [Design your first email](/email-studio/design-your-first-email).
  </Step>
</Steps>

## Which provider supports what

| Provider | `render()` | `deliver()` | Client configuration |
| --- | --- | --- | --- |
| **SendGrid domain** | Yes | Yes | `sendgridDomain` (required) |
| **Gmail ESP** | No, unless `sendgridDomain` is also set | Yes | `provider: 'gmail'` |
| **SMTP ESP** | No, unless `sendgridDomain` is also set | Yes | `provider: 'smtp'` |

`render()` always needs a SendGrid domain on the client. For Gmail-only or SMTP-only sending, preview templates in Email Studio, or add a SendGrid domain to use the render API.

## Client options

| Option | Description |
| --- | --- |
| `apiKey` | **Required.** Sent as the `x-api-key` header. |
| `sendgridDomain` | Your verified SendGrid domain, such as `mail.yourdomain.com`. **Required** when `provider` is `'sendgrid'` or omitted. Optional for Gmail and SMTP. |
| `provider` | `'sendgrid'`, `'gmail'` or `'smtp'`. Omitting it means SendGrid. |
| `baseUrl` | Optional. Defaults to `https://render.emailux.com`. A trailing slash is removed. |
| `defaultLocale` | Optional. Defaults to `en-US`. Used when a call omits `locale`. |
| `timeoutMs` | Optional. Aborts the request after this many milliseconds. |
| `fetchImplementation` | Optional. A custom `fetch`, for tests or edge runtimes. |

The constructor throws if `apiKey` is missing, or if SendGrid is selected without `sendgridDomain`.

<Warning>
  Use **`locale`** on each call, not `language`.
</Warning>

## Request headers

The client builds these headers for you. They match the REST API.

| Header | When it is sent |
| --- | --- |
| `x-api-key` | Always. |
| `x-sendgrid-domain` | `render()`, and `deliver()` when a SendGrid domain is set. |
| `x-provider` | `deliver()` with `gmail` or `smtp`. |

## `render()`

Calls `POST /v1/render` and returns HTML and the subject.

| Parameter | Description |
| --- | --- |
| `experienceId` | **Required.** The Email Studio email ID. |
| `version` | Optional template version number. |
| `locale` | Optional. Falls back to `defaultLocale`. |
| `data` | Optional object with your template variables. |

```ts
import { EmailUxApiClient } from '@emailux/api-client';

const client = new EmailUxApiClient({
  apiKey: process.env.EMAILUX_API_KEY!,
  sendgridDomain: 'your-verified-domain.com',
  defaultLocale: 'en-US',
  timeoutMs: 10000,
});

const rendered = await client.render({
  experienceId: 'welcome_email',
  locale: 'en-US',
  data: { nameTo: 'Alex' },
});

if (rendered.ok) {
  console.log(rendered.subject, rendered.html);
} else {
  console.error(rendered.status, rendered.error);
}
```

| Status | Meaning |
| --- | --- |
| `200` | Success. Returns `html` and `subject`. |
| `400` | Validation error. |
| `401` | Unauthorized. Check the API key. |
| `404` | Template not found. |

## `deliver()`

Calls `POST /v1/deliver`. It renders the template and sends it through your provider.

| Parameter | Description |
| --- | --- |
| `experienceId` | **Required.** The Email Studio email ID. |
| `channelData.toEmail` | **Required.** Recipient address. |
| `channelData.fromEmail` | **Required.** Sender address. |
| `channelData.toEmailName` | Optional recipient name. |
| `channelData.fromEmailName` | Optional sender name. |
| `version`, `locale`, `data` | Same as `render()`. |
| `provider` | Optional per-call provider override: `'gmail'`, `'smtp'` or `'sendgrid'`. |
| `sendgridDomain` | Optional per-call SendGrid domain override. |

Each call needs either a SendGrid domain or a `gmail` or `smtp` provider. Otherwise the client throws.

| Status | Meaning |
| --- | --- |
| `200` | Success. Returns `ok` and `message`. |
| `400` | Validation error. |
| `401` | Unauthorized. |
| `404` | Not found. |
| `502` | Provider error. |

### Deliver with a SendGrid domain

```ts
const client = new EmailUxApiClient({
  apiKey: process.env.EMAILUX_API_KEY!,
  sendgridDomain: 'your-verified-domain.com',
});

const sent = await client.deliver({
  experienceId: 'welcome_email',
  locale: 'en-US',
  channelData: {
    toEmail: 'alex@example.com',
    toEmailName: 'Alex',
    fromEmail: 'hello@your-verified-domain.com',
    fromEmailName: 'Your product',
  },
  data: { nameTo: 'Alex' },
});
```

Setup guide: [SendGrid](/providers/sendgrid).

### Deliver with Gmail

```ts
const client = new EmailUxApiClient({
  apiKey: process.env.EMAILUX_API_KEY!,
  provider: 'gmail',
  defaultLocale: 'en-US',
  timeoutMs: 10000,
});

await client.deliver({
  experienceId: 'welcome_email',
  locale: 'en-US',
  channelData: {
    toEmail: 'alex@example.com',
    toEmailName: 'Alex',
    fromEmail: 'your-connected-sender@example.com',
    fromEmailName: 'Your product',
  },
  data: { nameTo: 'Alex' },
});
```

`fromEmail` must match your connected sender. Setup guide: [Gmail](/providers/gmail).

### Deliver with SMTP

```ts
const client = new EmailUxApiClient({
  apiKey: process.env.EMAILUX_API_KEY!,
  provider: 'smtp',
  defaultLocale: 'en-US',
  timeoutMs: 10000,
});

await client.deliver({
  experienceId: 'welcome_email',
  locale: 'en-US',
  channelData: {
    toEmail: 'alex@example.com',
    fromEmail: 'your-connected-sender@example.com',
  },
  data: { nameTo: 'Alex' },
});
```

Setup guide: [SMTP and IMAP](/providers/smtp-imap).

### Override the provider per call

```ts
await client.deliver({
  experienceId: 'welcome_email',
  provider: 'gmail',
  channelData: { toEmail: 'alex@example.com', fromEmail: 'sender@example.com' },
});
```

### Render with SendGrid, send with Gmail or SMTP

Set both on one client to use the render API and still deliver through Gmail:

```ts
const client = new EmailUxApiClient({
  apiKey: process.env.EMAILUX_API_KEY!,
  provider: 'gmail',
  sendgridDomain: 'your-verified-domain.com',
});
```

## Handle errors

Every method returns an object instead of throwing on HTTP failures.

- HTTP `4xx` and `5xx` responses return `ok: false`, the `status`, and `error` with the parsed response body.
- Timeouts, aborts and network failures return `ok: false`, `status: 0` and `error.message`.
- Only configuration mistakes throw, such as a missing `apiKey`.

```ts
const result = await client.deliver(params);
if (!result.ok) {
  console.error(result.status, result.error?.message, result.error?.body);
}
```
