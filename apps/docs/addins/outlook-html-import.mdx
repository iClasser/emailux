The **EmailUX Outlook HTML Import Add-in** allows you to easily paste HTML code and insert it directly into a new Outlook email. This is useful when you want to send designed templates, announcements, or any custom HTML content through Outlook.

---

## How It Works

1. Install the add-in in Outlook.
2. Open a new email.
3. On the right side, open **EmailUX Outlook HTML Import**.
4. Paste your HTML into the box.
5. Click **Insert HTML**.
6. Your HTML will appear instantly inside the email body.

---

## What You Can Use It For

* Sending HTML email templates
* Adding formatted announcements
* Using EmailUX-designed templates
* Sending custom layouts inside Outlook
