The **EmailUX Gmail HTML Inserter** is a Chrome extension that lets you paste HTML and insert it directly into a Gmail compose window. Perfect for sending designed templates, announcements, or any custom HTML content through Gmail.

---

## How It Works

1. Install the Chrome extension named **"EmailUX HTML Inserter"** from the Chrome Web Store.
2. Open Gmail and click **Compose** to start a new email.
3. In the compose window, you will see an option labeled **EmailUX Insert HTML**.
4. Paste your HTML into the provided input.
5. Click **Insert HTML**.
6. Your HTML will be inserted into the email body instantly.

---

## What You Can Use It For

* Sending HTML email templates
* Adding formatted announcements
* Using EmailUX-designed templates
* Sending custom layouts inside Gmail
